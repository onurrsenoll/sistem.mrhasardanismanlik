## BÖLÜM 1: SİSTEME GİRİŞ VE TEMEL KULLANIM

### 1.1 İlk Giriş
1. Sistem yöneticinizden e-posta ve şifrenizi alın
2. Tarayıcıda sistem adresini açın (Chrome veya Firefox önerilir)
3. E-posta ve şifrenizi girin → GİRİŞ YAP
4. **İlk iş olarak şifrenizi değiştirin:** Sağ üst profil → PROFİL → Şifre Değiştir

### 1.2 Arayüz Tanıma
- **Üst Menü (Navbar):** Tüm modüllere erişim. Rolünüze göre menüler değişir.
- **Breadcrumb:** Sayfanın üstünde konumunuzu gösterir. Tıklayarak geri dönebilirsiniz.
- **Profil Menüsü:** Sağ üstte adınız görünür. Profil ve çıkış burada.
- **Bildirim Sayacı:** Kırmızı rakam okunmamış bildirimleri gösterir.
- **Footer:** "MR HASAR DANIŞMANLIK — HER ZAMAN FARK EDER"

## BÖLÜM 2: ROL BAZLI GÖREV REHBERİ

### 2.1 PERSONEL ROLÜ

**Erişim:** Ana Sayfa, Dosya İşlemleri, Ajanda, Bildirimler

#### Günlük İş Akışı:
1. Sisteme giriş yapın
2. Ana sayfadaki bildirimleri kontrol edin
3. Ajandadaki günlük görevleri gözden geçirin
4. Dosya işlemlerini gerçekleştirin

#### Dosya Oluşturma (Adım Adım):
```
1. DOSYA İŞLEMLERİ → YENİ DOSYA tıklayın
2. MAĞDUR BİLGİLERİ: Ad Soyad (zorunlu), TC, Telefon, Adres girin → İLERİ
3. DOSYA BİLGİSİ: Tür (ADK/BH), Talep Türü, Kaza Tarihi girin → İLERİ
4. ARAÇ BİLGİLERİ (ADK ise): Mağdur ve karşı araç bilgileri → İLERİ
5. ATAMA: Sigorta şirketi, dosya kaynağı, notlar → DOSYAYI KAYDET
6. Dosya numarasını not edin — bu numara ile takip yapılır
```

#### Dosya Detay İşlemleri:
```
MASRAF EKLEME:
1. Dosya detayında MASRAFLAR sekmesine geçin
2. YENİ MASRAF butonuna tıklayın
3. Masraf Kalemi seçin (Eksper Ücreti, Bilirkişi vs.)
4. Tutar girin → Kasa seçin → Tarih belirleyin → KAYDET
⚠️ Tutar kasa bakiyesinden otomatik düşülür!

EVRAK YÜKLEME:
1. EVRAKLAR sekmesine geçin
2. EVRAK YÜKLE butonuna tıklayın
3. Evrak Türü seçin (Kaza Tespit Tutanağı, Vekaletname vs.)
4. PDF dosya seçin (max 20MB) → YÜKLE

AŞAMA DEĞİŞTİRME:
1. Dosya detay sayfasında sağ üstteki dropdown'dan yeni aşamayı seçin
2. Aşamalar: Dosya Açık → Evrak Bekleniyor → Başvuru Hazırlanıyor → Sigorta Başvurusu → Tahkim Başvurusu → Dava Açıldı → Bilirkişi Aşaması → Karar Bekleniyor → Ödeme Bekleniyor → Ödeme Alındı → Dosya Kapandı
```

#### Ajanda Kullanımı:
```
1. AJANDA menüsüne gidin
2. TAKVİM görünümünde ilgili güne tıklayın
3. EKLE butonuna tıklayın
4. Başlık (zorunlu), Tarih (zorunlu), Öncelik, Açıklama girin → KAYDET
5. Görev tamamlandığında checkbox'a tıklayın
```

### 2.2 UZMAN ROLÜ

**Erişim:** Personel erişimi + Hesaplamalar

#### Ek Görevler — ADK Hesaplama:
```
1. HESAPLAMALAR → ARAÇ DEĞER KAYBI
2. Araç bilgilerini girin: Marka → Model → Yıl
3. Kaza tarihi, KM, Onarım Bedeli, Rayiç Değer girin
4. Hasar bölgesi seçin, kusur oranı belirleyin
5. HESAPLA butonuna tıklayın
6. Sonuçları dosyaya kaydedin veya PDF olarak çıktı alın
7. Emsal kararlar tablosunu inceleyerek rapor hazırlayın
```

#### Ek Görevler — BH Hesaplama:
```
1. HESAPLAMALAR → BEDENİ HASAR
2. Mağdur bilgileri: Ad, Doğum Tarihi, Cinsiyet
3. Maluliyet oranı (%), gelir bilgisi girin
4. PMF tablosu seçin (TRH2010 önerilen)
5. HESAPLA → Aktif/Pasif dönem gelir kaybını inceleyin
```

---

### 2.3 AVUKAT ROLÜ

**Erişim:** Uzman erişimi + CRM

#### CRM İş Akışı:
```
YENİ KAYIT:
1. CRM → YENİ KAYIT
2. Ad, Telefon (zorunlu), E-posta, İl, Tür, Kaynak girin
3. İlk görüşme notunu yazın → KAYDET

TAKİP:
1. CRM LİSTESİ'nden kaydı bulun
2. Durumu güncelleyin: Yeni → Takipte → Olumlu/Olumsuz
3. Her görüşmede not ekleyin

DOSYAYA DÖNÜŞTÜRME:
1. Olumlu CRM kaydını açın
2. DOSYAYA DÖNÜŞTÜR butonuna tıklayın
3. Bilgiler otomatik aktarılır — yeni dosya oluşur
```

---

### 2.4 MUHASEBE ROLÜ

**Erişim:** Dosya + Muhasebe + Ajanda + Bildirim

#### Muhasebe İşlemleri:

```
KASA KONTROLÜ:
1. MUHASEBE → KASA YÖNETİMİ
2. Tüm kasaların bakiyelerini kontrol edin
3. Gerekirse yeni kasa oluşturun

GELİR GİRİŞİ:
1. MUHASEBE → GELİR EKLE
2. Dosya no, tutar, kasa seçin → KAYDET

TRANSFER:
1. MUHASEBE → TRANSFER
2. Kaynak kasa → Hedef kasa → Tutar → TRANSFER

HAREKET KONTROLÜ:
1. MUHASEBE → HAREKETLER
2. Filtreler ile dönem ve kasa bazlı inceleyin
3. Tarih aralığı belirleyerek detaylı bakın

RAPOR:
1. MUHASEBE → RAPOR
2. Başlangıç ve bitiş tarihi seçin
3. Gelir/gider özeti ve detayları görüntüleyin
```

---

### 2.5 ADMİN ROLÜ

**Erişim:** Tüm modüller + Sistem Yönetimi

#### Sistem Yönetimi İşlemleri:

```
KULLANICI OLUŞTURMA:
1. SİSTEM → KULLANICI YÖNETİMİ → YENİ KULLANICI
2. Ad Soyad, E-posta, Şifre, Telefon girin
3. Rol seçin: Admin/Avukat/Uzman/Personel/Muhasebe/Portal
4. KAYDET

TANIMLAMA YÖNETİMİ:
1. SİSTEM → TANIMLAMALAR
2. Sol panelden kategori seçin (Sigorta Şirketleri, Masraf Kalemleri vs.)
3. YENİ EKLE ile değer ekleyin
4. Sürükle-bırak ile sıralama değiştirin
5. Aktif/Pasif durumu yönetin

LOG İZLEME:
1. SİSTEM → LOG KAYITLARI
2. Tüm işlemleri inceleyin (kim, ne zaman, ne yaptı)
3. IP adresi ve detay bilgisi görüntüleyin

BİLDİRİM GÖNDERME:
1. BİLDİRİMLER → BİLDİRİM GÖNDER
2. Hedef seçin (belirli kullanıcı veya TÜMÜ)
3. Tür, başlık, mesaj yazın → Önizleme kontrol → GÖNDER
```

## BÖLÜM 3: EN SIK YAPILAN HATALAR VE ÇÖZÜMLER

| Hata | Neden | Çözüm |
|------|-------|-------|
| Dosya kaydedilmiyor | Mağdur adı boş | Adı Soyadı alanını doldurun |
| Masraf eklenmiyor | Kalem veya tutar boş | Tüm zorunlu alanları doldurun |
| Evrak yüklenmiyor | PDF değil veya 20MB üstü | Sadece PDF, max 20MB |
| Şifre değişmiyor | Eski şifre yanlış veya yeni şifre 6 karakterden kısa | Doğru bilgileri girin |
| Menü görünmüyor | Rolünüzde yetkisi yok | Admin'den yetki isteyin |
| Kasa bakiyesi yanlış | Masraf silinmiş/eklenmiş | Hareketler sekmesinden kontrol edin |
