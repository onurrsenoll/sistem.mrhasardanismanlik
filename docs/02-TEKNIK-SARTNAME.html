2.3 HESAPLAMA MODULU

ADK - Tahkim Formulu (2024-2026)

DK = Rayic x BazOran x YasK x KMK x BolgeK x OncekiK x (Kusur/100)
KATSAYIDEGERLER
Baz Oran%3 (hasar≤3%) ~ %22 (hasar>40%)
Yas Katsayisi1.00 (0-1 yil) ~ 0.18 (15+ yil)
KM Katsayisi1.00 (<10k) ~ 0.40 (250k+)
Bolge KatsayisiOn:1.00, On+Yan:0.95, Yan:0.90, Arka:0.85, Tavan:0.75, Alt:0.70
Onceki Hasar0:1.00, 1:0.82, 2:0.68, 3:0.55, 4:0.42, 5+:0.30

ADK - Yargitay Ictihadi (17. HD / 4. HD)

DK = Rayic x HasarEtkisi x (1 - Yipranma) x BolgeK x OncekiK x (Kusur/100) Yipranma = min(YasYipranma + KMYipranma, 0.50) YasYipranma = min(aracYasi x 0.035, 0.40) KMYipranma = min(floor(km/50000) x 0.025, 0.20)

BH - Bedeni Hasar Hesaplama

AktifGelirKaybi = AylikGelir x 12 x (Maluliyet/100) x AktifRant PasifGelirKaybi = PasifAylikGelir x 12 x (Maluliyet/100) x PasifRant x PasifIskonto ToplamNet = max(0, (Aktif + Pasif + GIGS + Bakici) x (Kusur/100) - PSD)
PARAMETREACIKLAMA
PMF TablolariTRH2010, CSO1980, PMF1931
Teknik Faiz%1.8, %0, %1.65, %10
Emeklilik YasiVarsayilan 65, ayarlanabilir (55-75)
Vergi Dilimi%15 (≤200k), %17 (≤400k), %19 (≤700k), %21 (>700k)
Rant YontemiProgresif (1/Ln metodu)
